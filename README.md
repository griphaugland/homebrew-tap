# griphaugland/homebrew-tap

Homebrew formulas and casks for [griphaugland](https://github.com/griphaugland) projects.

## Bouncer

Queues heavy builds by memory pressure so many AI coding agents can share one Mac.
See [griphaugland/bouncer](https://github.com/griphaugland/bouncer).

```sh
brew install griphaugland/tap/bouncer          # CLI + daemon
bouncer install                                # daemon, shims, Claude Code hooks
brew install --cask griphaugland/tap/bouncer   # menu bar app (optional)
```

Formula and cask are generated by Bouncer's release workflow from each release's checksums;
don't edit them by hand.
